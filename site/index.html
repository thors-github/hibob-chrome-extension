02Manual setup

GitHub release ZIP

Download the built extension, extract it once, and load its folder in Chrome.

  1. Download the built extension ZIP from your chosen release and extract it into a permanent folder. New releases use hibob-monthly-attendance.zip.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose Load unpacked and select the folder containing manifest.json.
  4. Open HiBob’s My attendance page, click the extension icon, then choose Read month.

Keep it current

Know how your copy updates.

Installed from the Store

After publication, Chrome checks for approved Store updates. A GitHub release alone does not update a Store installation. Apply a downloaded update only when no attendance scan or booking is running.

Installed from a ZIP

Updates are manual: replace the files in the same installation folder, reload the extension in chrome://extensions, then reload HiBob. Finish any active operation first.

Moving from ZIP to Store

Export preferences from your old copy, install the Store copy, import the preferences, and disable the old copy. Previews and run history are not transferred; read the month again.

Local by design

Your attendance stays in your workflow.

No project backend, analytics, or external holiday lookup. Settings stay in local Chrome storage; HiBob receives only the form submissions you confirm.
